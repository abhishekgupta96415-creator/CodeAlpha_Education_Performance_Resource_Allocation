# 📊 Education Performance & Resource Allocation Dashboard
## 📌 Project Overview
The **Education Performance & Resource Allocation Dashboard** is an interactive Power BI project developed as part of the **CodeAlpha Power BI Internship**.
The dashboard provides insights into student academic performance, attendance, pass/fail rates, teacher availability, and educational resource utilization. It helps educational institutions make data-driven decisions and identify areas that require improvement.
---

## 🎯 Objectives
- Analyze student academic performance.
- Monitor attendance and pass rates.
- Compare performance across subjects, grades, and departments.
- Analyze educational resource budgets and usage.
- Identify resource utilization patterns.
- Analyze student-teacher ratios.
- Provide interactive insights through Power BI dashboards.
---

## 📊 Dashboard Pages
### 1️⃣ Education Overview
Provides a high-level overview of educational performance.

**Key Metrics:**
- Total Students
- Average Marks
- Pass Rate
- Average Attendance
- Total Teachers
- Resource Utilization

**Visualizations:**
- Average Marks by Subject
- Average Marks by Grade
- Attendance vs Academic Performance
- Student Pass/Fail Distribution

---
### 2️⃣ Student Performance Analysis
Focuses on detailed academic performance.
**Key Metrics:**
- Total Students
- Average Marks
- Average Attendance
- Pass Rate

**Visualizations:**
- Subject-wise Academic Performance
- Pass/Fail by Subject
- Average Marks by Department
- Attendance by Grade
---
### 3️⃣ Resource Allocation & Utilization
Analyzes institutional resources and budget utilization.
**Key Metrics:**
- Total Resources Budget
- Total Resources Used
- Unused Budget
- Resource Utilization

**Visualizations:**
- Resource Usage by Type
- Budget vs Resource Usage by Department
- Student-Teacher Ratio by Department
- Resource Utilization by Department
